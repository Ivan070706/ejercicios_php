
# 🐘 EJERCICIOS PHP – 1º DAW

Repositorio donde recopilo los ejercicios y prácticas realizados durante el ciclo formativo de **Desarrollo de Aplicaciones Web (DAW)**.

El objetivo es practicar los fundamentos de PHP y mejorar progresivamente mis conocimientos de programación.

## 📁 Estructura del proyecto

```text

├── relacion_2/
```

## 📚 Contenido

### 🔹 Relación 1
Ejercicios de introducción a PHP:

- Hola Mundo.
- Variables y superglobales.
- Arrays y arrays asociativos.
- Creación de objetos.
- Cálculos y operaciones matemáticas.
- Estructuras condicionales (`if` y `switch`).
- Bucles (`for`).
- Números primos y divisores.
- Máximo común divisor.
- Conversión de números entre sistemas de numeración.

## ▶️ Cómo utilizar el proyecto

1. Clonar o descargar este repositorio.
2. Abrir la carpeta del proyecto.
3. Iniciar un servidor local compatible con PHP, como Apache mediante XAMPP.
4. Acceder desde el navegador a `super_index.html` a través del servidor.
5. Seleccionar la relación de ejercicios que se quiera consultar.
